
# At My Night Shift I'm a Werewolf

A 2D game developed using Godot.

## Tech Stack
- Godot Engine
- GDScript

## Project Structure

```text
assets/
  images/
    player-normal/
    player-werewolf/

scenes/
  player.tscn

scripts/
  player.gd

main.tscn
project.godot
```

## How to Run

1. Clone this repository.
2. Open Godot Engine.
3. Import the project by selecting `project.godot`.
4. Run the project using F6 or F5.
